# AgendAI — Frontend

SPA React + Vite do AgendAI.

> **Manual para IAs e contribuidores:** [`AGENTS.md`](./AGENTS.md) · inventários em [`docs/agents/`](./docs/agents/)

## Rodar localmente

**Pré-requisitos:** Node.js ≥ 22.13

```bash
npm install
cp .env.example .env   # preencher o necessário
npm run dev
```

Comandos úteis: `npm run typecheck`, `npm test`, `npm run lint`, `npm run docs:check`, `npm run test:e2e`.

Não confundir com o projeto separado `agendai-nextjs` no workspace.
